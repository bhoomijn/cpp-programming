# C++ Programming 🚀

Welcome to my **C++ Programming** repository — a structured, hands-on journey to building strong programming fundamentals and problem-solving skills through consistent practice.

This repository contains my learning progress, concept-wise implementations, coding exercises, and **competitive programming solutions**, with a focus on writing clean, understandable, and efficient C++ code.

## 📚 What You'll Find

### Fundamentals
* **Variables & Datatypes** - Declaration, initialization, and basic data types
* **Input/Output Operations** - `cin` and `cout` for user interaction
* **Operators** - Arithmetic, logical, comparison, and bitwise operators
* **Conditional Statements** - `if`, `else if`, `else`, and `switch` statements
* **Loops** - `for`, `while`, `do-while` loops and nested loops

### Intermediate Concepts
* **Functions** - Function definition, parameters, return types, and scope
* **Arrays & Strings** - Single/multi-dimensional arrays and string manipulation
* **Pointers & References** - Memory addresses, pointer arithmetic, and references
* **Dynamic Memory** - `new` and `delete` operators, memory management

### Advanced Topics
* **Object-Oriented Programming (OOP)**
  - Classes and objects
  - Constructors and destructors
  - Inheritance and polymorphism
  - Encapsulation and abstraction

* **Standard Template Library (STL)**
  - Containers (`vector`, `list`, `map`, `set`)
  - Iterators
  - Algorithms
  - Functors and lambdas

### Problem Solving
* Competitive programming problems from various platforms
* Coding challenges and exercises
* Real-world application examples
* Algorithm implementations

## 🚀 Quick Start

### Prerequisites
- GCC/G++ compiler installed
- Basic command line knowledge
- A text editor or IDE

### Compile & Run a Program

```bash
# Navigate to cpp-programming directory
cd cpp-programming/

# Compile a C++ file
g++ -o program_name program_name.cpp

# Run the compiled program
./program_name

# Or compile and run in one command
g++ -o output_name program_name.cpp && ./output_name
```

### Example: Running Variables & Datatypes Programs

```bash
# Navigate to the folder
cd "Variables & Datatypes"

# Compile and run the first program
g++ -o 01_basic_output 01_basic_output.cpp && ./01_basic_output

# Compile and run the data types program
g++ -o 03_data_types 03_data_types.cpp && ./03_data_types
```
